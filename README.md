# 折间 ORI

## 本地启动

```sh
npm install
npm run dev
```

## 联动折叠

按住 Shift 点选折痕，或开启画面下方工具条中的「⬚」框选按钮后用鼠标框住多条折痕，然后在右侧「联动折叠」面板中建立关系：

- **同角**：随动折痕与主动折痕角度相同。
- **反向**：随动折痕取相反符号。
- **比例**：随动折痕 = 主动折痕 × 系数（可跨父子纸面）。

拖动滑杆、拖动画面中的折痕或使用预设角度时，整组会按关系同动；角度正负始终以各折痕自身局部折轴为准，旋转相机不会改变山谷方向。

闭环约束会自动区分「冗余」（与已有关系一致）与「矛盾」（无解）。矛盾关系会保留在面板中标红以便修改或删除，但不会参与求解，画面保持上一次完整形态。任一折痕到达 ±175° 时整组按比例一起停住，不会只让部分纸面继续运动。

「保存当前步骤」会把角度与联动关系一起写入当前步骤；播放与单步还原走同一条求解路径，结果完全一致。解除关系后各折痕恢复独立编辑，形态不会跳变。
